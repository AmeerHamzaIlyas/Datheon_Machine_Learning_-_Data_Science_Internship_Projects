# Machine Learning Projects Portfolio

A practical 4-week Machine Learning program focused on building end-to-end predictive models using Python, Pandas, NumPy, Matplotlib, and Scikit-Learn.

This repository contains four hands-on projects covering classification, regression, customer churn prediction, and Natural Language Processing (NLP).

## 📌 Projects Overview

### 1. Multi-Class Benchmark Classification
**Iris & Wine Datasets**

- Build classification pipelines using Scikit-Learn.
- Apply data preprocessing and feature scaling.
- Train and compare multiple classification algorithms.
- Evaluate performance using accuracy and confusion matrices.

### 2. Real Estate Housing Price Prediction
**Ridge & Lasso Regression**

- Perform exploratory data analysis (EDA).
- Handle missing values and preprocess features.
- Apply feature engineering and normalization.
- Train Ridge and Lasso regression models.
- Evaluate predictions using regression metrics and residual analysis.

### 3. Predictive Customer Churn Classification
**Random Forest & XGBoost**

- Preprocess telecom customer subscription data.
- Handle class imbalance using SMOTE or class weighting.
- Train Random Forest and XGBoost classifiers.
- Optimize and compare ROC-AUC performance.
- Analyze feature importance and confusion matrices.

### 4. NLP Sentiment Classification
**TF-IDF, Multinomial Naive Bayes & Logistic Regression**

- Clean and preprocess customer/movie reviews.
- Apply tokenization, stopword removal, and lemmatization.
- Convert text into numerical features using TF-IDF.
- Train and compare sentiment classification models.
- Build an interactive sentiment prediction function.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

Navigate to the project directory:

```bash
cd your-repository
```

Install the required dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn xgboost imbalanced-learn nltk jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the desired project notebook and run the cells.
